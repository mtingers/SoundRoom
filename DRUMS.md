# Original drums and loop designer

Open **Edit → Drum Loop Designer…** (⇧⌘B), or **Beats** in the editor. The designer owns its transport: Space plays/stops its loop and never starts the editor behind it. Escape stops; arrow keys select a cell; Return toggles it; Delete removes it. ⌘Z/⇧⌘Z undo/redo, ⌘C/⌘V copy/paste the active pattern, ⌘D duplicates it, and ⌘S saves the pattern bank. Text fields and nested file panels retain native keyboard editing.

Click cells to toggle hits. Option-click selects a hit without toggling it, then adjust Velocity, Pan or Chance below. Right-click a cell for common velocity choices. The vertical bars inside active cells show velocity. Choose length (1–8 bars), grid (1/8–1/32), tempo, swing and deterministic humanize. Lower Level if many sounds overlap. Per-sound controls choose any kit independently, with damping, ±12 semitones of tuning, gain, pan and mute. Acoustic studio, maple jazz, birch rock, vintage dry, brushes, orchestral and electronic models can be mixed in one pattern. Each changes the excitation, resonance, wire/body balance or metallic mode spectrum. Selected snare steps support center, rimshot, side stick and brush; toms support rimshot, and ride/crash support bell strikes. These remain synthesized instruments, not recorded kits.

**Performance** chooses one, two, four or eight passes with varying strikes, chance, timing and velocity. Each voice uses eight strike variations and continuous velocity response. Variation is deterministic so preview, insertion and export agree. Timing and velocity variation have separate controls; new acoustic patterns start with subtle variation across four passes. A four-pass one-bar pattern inserts/exports four bars, including wrapped cymbal tails.

Pattern presets include backbeat, four on the floor, breakbeat and half-time. The Pattern menu creates, duplicates, copies/pastes and saves/opens a bank of up to 32 named patterns as `.soundroomdrums` files. The active pattern inserts as stereo audio in the current track at the editor playhead. Double-click a Beats clip or choose **Edit beats** on the track to open its inline editor; **Full drum designer…** opens the detailed editor. All bars appear in one labeled horizontal grid, with scrolling for longer patterns. Increasing length repeats the groove into independent new bars. Trims, splits and copied ranges retain the pattern; updating preserves the clip identity, position and source window, so it cannot restore audio outside the trimmed range. Older trims can recover their pattern when their history still contains the matching unchanged audio source.

**Export WAV…** writes dry stereo 24-bit/48 kHz audio with the selected mix. The same synthesis and render path drives preview, insertion and export. Cymbal tails wrap across the loop boundary, and closed hats choke open hats with a short release. Inserted drum clips end at the musical loop boundary, including the chosen performance passes, without an appended decay tail. Exported files include the decay tail. Inserted drum clips use automatic 2 ms edge protection. Adjacent unchanged copies of the same full loop join continuously, while isolated clip edges and later audio edits remain protected. The designer preview uses the continuous loop directly; transport protection still applies when starting/stopping. Export/insertion reject an overloaded loop rather than silently clipping or changing its dynamics.

## Sample pack

Run `zsh scripts/generate-drum-pack.sh build/DrumPacksExpanded` (optionally choose another output folder). This generates 4,032 original mono 24-bit/48 kHz WAV samples: seven kits × nine voices × eight velocities × eight round robins. It also writes seven four-bar stereo demos, `manifest.json`, `README.md` and `LICENSE.txt`.

The acoustic-style kits use physically inspired membrane/modal cymbal/snare-wire models; they are not recorded acoustic audio. The electronic kit uses original pitch envelopes, resonant oscillators, noise and metal synthesis. Harder acoustic strikes change tone as well as level. Round robins vary strike position, tuning and excitation. All samples are dry, with fixed headroom, silent endpoints, and no peak normalization, reverb, compression or limiting. Audio files are dedicated under CC0-1.0; repository source licensing remains unchanged.

Validation covers every layer and round robin for finite output, unclipped headroom, audible output and silent tails; acoustic layers have different normalized waveforms and round robins differ; WAV headers and quantization verify PCM24/48 kHz/mono. Pattern tests cover deterministic synthesis, swing, long cymbal tail wrap, stereo routing, mixed kits, tuning, mute, chance and hat choking. Integration tests cover gesture undo, pattern banks/clipboard/validation, metadata roundtrip/editable fragments, transport isolation and asynchronous insertion/update/undo.

The expanded pack exports default center articulations at MIDI velocities 16, 32, 48, 64, 80, 96, 112 and 127. Articulation editing and continuous velocity remain available in the app. Validation reads each delivered PCM file independently, checks its manifest, headroom, endpoints, layer timbre and every acoustic robin, and produces checksums and a ZIP. The earlier two-kit 162-file pack is retained separately.
